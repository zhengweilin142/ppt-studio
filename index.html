大纲语法

# 标题整个文稿的主标题（写在第一行）
## 小节一页内容页，标题即页标题
- 要点一条要点；1. * • 同样识别
  - 子要点缩进两个空格 → 二级要点
@stats下一行起 - 指标: 数值 → 数据卡片页
@table下一行起 Markdown 表格 → 表格页
@timeline- 2025 Q3: 描述 → 时间轴页
@quote引用页；> 句子 —— 出处 也会自动识别
@two-col两栏对比页
@section章节过渡页
---分隔线，用于切断当前块

没有 Markdown 结构也没关系：连续的文字段落会按「一段一页、首句作标题」自动分页。
